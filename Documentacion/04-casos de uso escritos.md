=== CASOS DE USO ===

1- el admin crea un usuario para tens y para maestro
2- los profesores pueden crear una ficha de paciente
3- los profesores pueden poner a prueba a las estudiantes tens para simular el caso de cuando llegan como trabajadoras nuevas en un lugar donde ya hay pacientes registrados para que las alumnas tengan que interpretar en base a datos ya ingresados.
4- las estudiantes de tens pueden visualizar e ingresar pacientes para casos de simulacionn  en las clases.
5- el administrador tiene todos los permisos.
6- los alumnos de tens no deben vizualisar y tampoco modificar las fichas creadas por otros alumnos tens.
7- el administrador puede modificar los permisos de tens y docente.
